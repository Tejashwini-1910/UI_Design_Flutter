# 🧩 Experiment 10(a): Write Unit Tests for UI Components

## 🎯 Aim
To write unit tests for Flutter UI components to ensure they behave as expected.

## 🧠 Concept
Flutter provides a built-in testing framework for:
- **Unit Tests** → test logic and methods.
- **Widget Tests** → test UI components.
- **Integration Tests** → test complete app flows.

In this experiment, we’ll write a **widget test** to verify UI behavior (like a counter increment).

## ⚙️ Procedure
1. Create a Flutter project.
   ```bash
   flutter create ui_testing
   cd ui_testing
2. Open the test/widget_test.dart file.
3. Write a widget test for a simple Counter App.
4. Run the test using: flutter test
