# Experiment 1(a): Install Flutter and Dart SDK

## Aim
To install Flutter and Dart SDK and verify the installation.

## Procedure
1. Download and install Flutter SDK from the [official Flutter website](https://flutter.dev/docs/get-started/install).
2. Add the Flutter SDK path to the system environment variables.
3. Install Dart SDK (it comes bundled with Flutter).
4. Run the command to verify installation: flutter doctor
5. Ensure all checks are green!
