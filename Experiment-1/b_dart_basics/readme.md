# Experiment 1(b): Simple Dart Program

## Aim
To write and execute a simple Dart program to understand language basics.
## Procedure
Open VS code or Notepad. Create main.dart file.

## Program (main.dart)
void main() {
  print('Welcome to Dart Programming!');
  int a = 10;
  int b = 20;
  int sum = a + b;

  print('The value of a: $a');
  print('The value of b: $b');
  print('Sum of a and b: $sum');

  String name = 'Flutter Lab';
  print('This is $name experiment.');
}

## To run the program use command: dart run main.dart
