# Experiment 5(a): Learn about Stateful and Stateless Widgets

## 🎯 Objective
To understand the difference between **Stateful** and **Stateless** widgets in Flutter and how they manage UI changes.

---

## 🧠 Theory

### 🪶 **Stateless Widget**
- A widget that **does not change** once it is built.  
- Used for static UI elements.  
- It is immutable — meaning its properties can’t change during runtime.


### 🪶 **Stateful Widget**
-A widget that can **change** its state dynamically during runtime.
-It uses a State class to rebuild parts of the UI when data changes.
-Ideal for user interactions like button clicks, forms, counters, etc.
