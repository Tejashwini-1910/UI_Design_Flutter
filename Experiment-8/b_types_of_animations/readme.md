# 🌀 Experiment 8(b): Experiment with Different Types of Animations (Fade, Slide, Scale)

## 🎯 Aim
To experiment with various types of animations such as Fade, Slide, and Scale in Flutter.

## 🧠 Concept
Flutter provides multiple animated widgets to simplify animation tasks:
- `AnimatedOpacity` → for fade animations
- `SlideTransition` → for sliding motion
- `ScaleTransition` → for scaling effects

## ⚙️ Procedure
1. Create a Flutter project or use the same one as previous.
2. Add multiple widgets to demonstrate different animations.
3. Implement `FadeTransition`, `SlideTransition`, and `ScaleTransition`.
4. Observe how each effect behaves differently.
