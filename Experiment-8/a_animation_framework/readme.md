# 🧩 Experiment 8(a): Add Animations to UI Elements using Flutter’s Animation Framework

## 🎯 Aim
To add animations to UI elements using Flutter’s built-in animation framework.

## 🧠 Concept
Flutter provides a powerful animation library that allows smooth transitions and motion effects using classes like:
- `AnimationController`
- `Tween`
- `AnimatedBuilder`
- `CurvedAnimation`

These help in creating controlled animations with ease.

## ⚙️ Procedure
1. Create a new Flutter project.
2. Replace the lib/main.dart code with animation logic.
3. Use an AnimationController and Tween to animate a widget’s size or opacity.
4. Run the app to observe smooth animation transitions.
