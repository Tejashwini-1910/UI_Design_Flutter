# Experiment 4(a): Navigation Using Navigator

## Objective
To navigate between two screens using `Navigator.push()` and `Navigator.pop()`.

## Description
- `Navigator.push()` moves to a new screen.
- `Navigator.pop()` returns to the previous screen.
